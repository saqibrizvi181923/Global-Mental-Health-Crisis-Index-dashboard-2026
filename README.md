# Global Mental Health Crisis Dashboard

## Dashboard Overview

Global MH Crisis - Dashboard.png

## Overview
This project presents an interactive Power BI dashboard that analyzes global mental health indicators across countries.

## Objectives
- Identify countries with the highest mental health crisis levels.
- Analyze treatment gaps.
- Examine the relationship between mental health spending and crisis levels.
- Compare depression, anxiety, and suicide rates globally.

## Tools Used
- Power BI
- Power Query
- DAX
- CSV Dataset

## Key KPIs
- Average Depression %
- Average Anxiety %
- Average Suicide Rate per 100K
- Average Treatment Gap %
- Average Mental Health Crisis Index

## Visualizations
- Top Countries by Crisis Index
- Mental Health Spending vs Crisis Index
- Treatment Gap by Income Group
- Suicide Rate by Region
- Mental Health Policy Analysis
